## 🛠 Команды для жизни

### 🔥 `npm start`
Запускает дев-сервер. Открывай `http://localhost:3000` и коди.

```bash
npm start
```

### 🧪 `npm test`
Тесты в режиме слежки. Пока пишешь — они бегут.

```bash
npm test
```

### 📦 `npm run build`
Собирает прод. Всё минимизировано, хешировано, готово к выкату.

```bash
npm run build
```

### 💀 `npm run eject`
Навсегда. Вытаскивает все конфиги. Обратно дороги нет. Думай, братан.

```bash
npm run eject
```
